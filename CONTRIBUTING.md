# Contributing to Xemantic Projects

Thank you for your interest in contributing to Xemantic!
We build humanistic code for the betterment of society —
contributions that share this mission are very welcome.

## Contributor License Agreement (CLA)

Before we can accept your contribution, you must sign our Contributor License Agreement.
This is a one-time requirement covering all Xemantic projects — sign once, contribute everywhere.
It protects both you and the project.

**Why a CLA?**

- Ensures you have the right to contribute the code
- Grants the project necessary rights to distribute your contribution
- Protects the project's ability to be distributed under its chosen license
- Provides legal clarity for all parties

When you open your first pull request, the [CLA Assistant](https://cla-assistant.io/) will automatically ask you to sign the CLA.
The process is simple:

1. Open a pull request
2. CLA Assistant will comment with a link
3. Sign the CLA by authenticating with your GitHub account
4. Your signature is recorded, and you won't need to sign again for any Xemantic project

The full CLA text is available at [CLA.md](https://github.com/xemantic/.github/blob/main/CLA.md).

## Ways to Contribute

- **Report bugs** - Open an issue describing the problem and how to reproduce it
- **Suggest features** - Open an issue describing your idea and its use case
- **Submit pull requests** - Fix bugs, improve documentation, or add features
- **Join discussions** - Participate in issue discussions and our [Discord server](https://discord.gg/vQktqqN2Vn)

## Pull Request Process

1. Fork the repository and create your branch from `main`
2. Make your changes, following the existing code style
3. Add tests if applicable
4. Ensure all tests pass
5. Submit a pull request with a clear description of your changes

Pull requests are reviewed by maintainers and may receive automated feedback from Claude Code.

## Development Guidelines

- Keep changes focused and minimal
- Write clear commit messages
- Follow existing patterns in the codebase
- Document public APIs

## Code of Conduct

All contributors are expected to follow our [Code of Conduct](https://github.com/xemantic/.github/blob/main/CODE_OF_CONDUCT.md).

## Questions?

- Open an issue for project-specific questions
- Join our [Discord](https://discord.gg/vQktqqN2Vn) for general discussion
- Visit [xemantic.com](https://xemantic.com) to learn more about us
